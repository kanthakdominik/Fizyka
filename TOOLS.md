# Narzędzia (wszystkie darmowe)

Do nauki z tego repozytorium wystarczy przeglądarka i smartfon. Python jest potrzebny w zadaniach obliczeniowych i w module 25.

## Doświadczenia i symulacje

| Narzędzie | Do czego | Gdzie w repozytorium |
|---|---|---|
| [phyphox](https://phyphox.org/) (Android, iOS) | Pomiary czujnikami smartfona: akcelerometr, żyroskop, mikrofon, magnetometr, barometr, czujnik światła. Eksport danych do CSV | Sekcje „Doświadczenie” w modułach 01–15 |
| [PhET](https://phet.colorado.edu/) (przeglądarka) | Gotowe symulacje do sprawdzenia intuicji przed rachunkami | Większość modułów |
| [Tracker](https://physlets.org/tracker/) (Windows, macOS, Linux) | Analiza ruchu z nagrania wideo: położenie klatka po klatce, dopasowanie modelu | 02, 05, 06, 09 |
| [Stellarium](https://stellarium.org/) | Planetarium na komputer — obserwacje do elementów astronomii | 07 |

## Obliczenia i wykresy

| Narzędzie | Do czego |
|---|---|
| Python 3.12 + `numpy`, `scipy`, `matplotlib` | Opracowanie pomiarów, dopasowanie modeli, symulacje (`pip install numpy scipy matplotlib`) |
| `sympy` (opcjonalnie) | Rachunek symboliczny: sprawdzanie pochodnych, całek, rozwiązań równań różniczkowych |
| [JupyterLab](https://jupyter.org/) (opcjonalnie) | Notatniki do własnych opracowań |
| [Desmos](https://www.desmos.com/calculator) / [GeoGebra](https://www.geogebra.org/) | Szybkie wykresy funkcji, wektory, konstrukcje w optyce geometrycznej |

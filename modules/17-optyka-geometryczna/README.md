# 17 — Optyka geometryczna

> **Status:** 🔲 szkielet · **Poziom:** 🟢 · **Odpowiednik:** Fizyka II — optyka · **Czas:** 20–35 h od zera

## Cel modułu

Konstruować i liczyć obrazy w zwierciadłach i soczewkach, stosować prawo załamania i całkowite wewnętrzne odbicie, rozumieć działanie przyrządów optycznych.
